# IoT-Fire-Alarm

## Project Overview

An IoT-based fire alarm system using an ESP8266 and five flame sensors.

The system monitors five detection points. When a flame is detected, the buzzer is activated and a notification is sent to the LINE application with the detected position.

## Hardware

- ESP8266
- 5 Flame Sensors
- Buzzer

## Technologies

- ESP8266
- Arduino (C/C++)
- Wi-Fi
- LINE Notify

## Features

- Monitor five flame detection points
- Activate buzzer when a flame is detected
- Identify the detected flame position
- Send flame detection notifications to LINE

## How It Works

1. The ESP8266 connects to Wi-Fi.
2. Five flame sensors monitor different detection points.
3. The ESP8266 reads the sensor values.
4. When a flame is detected, the buzzer is activated.
5. The system sends a notification to LINE indicating the detected position.
